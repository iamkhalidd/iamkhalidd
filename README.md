### About Me

I work at the intersection of cybersecurity, full-stack software engineering, and financial systems. My technical foundation spans Linux administration (Kali, Alpine, Ubuntu), cloud infrastructure on AWS, and Python-based automation and tooling, built independently alongside my formal engineering career. On the financial systems side, I apply the same engineering discipline to algorithmic trading, designing and stress-testing MetaTrader 5 systems where risk management is treated with the same rigor as production code.

I currently lead backend delivery on a telemedicine platform serving the German market, with responsibility spanning the clinical workflow service, platform API, and AI services layer.

<br>

### What I Do

**Cybersecurity & Digital Forensics**
Penetration testing, vulnerability assessments, and forensic investigations using custom Python tools. Network anomaly detection, phishing analysis, incident response.

**Full-Stack Web Development**
Production applications in React, TypeScript, and Node.js. E-commerce platforms, client portals, booking systems, logistics dashboards.

**Python Security Tools & Automation**
Custom CLI tooling: forensic toolkits, fraud detection systems, log analyzers, automation scripts.

**Trading Systems & FinTech**
Algorithmic trading bots for MT5, AI-assisted market analysis platforms, real-time fraud detection, financial risk management tools.

**SaaS Product Development**
End-to-end platforms with authentication and admin tooling: event management, rental systems, logistics tracking, workflow tools.

**Cloud & DevOps**
AWS infrastructure, Docker, Firebase, Vercel deployments, Linux server administration across Kali, Alpine, and Ubuntu.
